# CSV Studio 🚀 (PWA)

Nowoczesny, szybki, lekki i intuicyjny edytor arkuszy CSV, TSV i XLSX jako **Progressive Web App (PWA)** dla Windows.

---

## 🚀 Jak Uruchomić:

* **Windows**: Kliknij dwukrotnie plik **`Uruchom_Windows.bat`** (lub `uruchom.vbs`).
* **macOS (Mac)**: Kliknij dwukrotnie plik **`Uruchom_Mac.command`**.
* **Linux**: Uruchom w terminalu **`./Uruchom_Linux.sh`**.

Aplikacja otwiera się w Twojej przeglądarce pod adresem `http://127.0.0.1:8765`.

### 📲 Instalacja jako aplikacja na Pulpicie / Docku (PWA):
W Google Chrome, Microsoft Edge, Safari lub Brave kliknij ikonę **„Zainstaluj”** w pasku adresu. Na Twoim Pulpicie / Docku pojawi się skrót z zieloną ikoną **CSV Studio**, który otwiera program w osobnym, dedykowanym oknie aplikacji działającym w 100% offline!

---

## ✨ Główne Funkcje:

- ⚡ **Koniec z psuciem danych**: Brak ucinania zer wiodących (`00123`), brak automatycznej konwersji na daty.
- 📌 **Zamrażanie Okienek (Freeze Panes)**: Blokowanie wierszy i kolumn w 100% zintegrowane z historią `Ctrl+Z` / `Ctrl+Y`.
- 🟩 **Przeciąganie w dół (Fill Handle) & `Ctrl+D`**: Inteligentne powielanie wartości i generowanie serii.
- 👁️ **Ukrywanie Pustych Kolumn (Clean View)**: 1 kliknięcie chowa nieużywane kolumny w szerokich bazach SKU.
- 🌪️ **AutoFilter**: Lejki filtrujące w nagłówkach z wyszukiwarką unikalnych wartości i licznikami.
- 💾 **Prawdziwy Zapis na Dysku (`Ctrl+S`)**: Bezpośredni zapis do otwartego pliku przez *File System Access API*.
- 🌓 **Ciemny / Jasny Motyw**: Elegancki interfejs z możliwością szybkiego przełączania.
